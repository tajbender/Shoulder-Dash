# Shoulder-Dash
Shoulder-Dash for Lorraine Computers

> Carry the weight of technical debt on your shoulders.

Shoulder-Dash is a light-hearted retro puzzle-action game inspired by classic cave exploration games of the 1980s and 1990s.

Instead of collecting precious gems, players navigate dangerous underground code repositories, gather productivity, avoid bugs, and survive the constant collapse of software dependencies.

The game combines classic falling-object mechanics with modern software development humor.

---

## Story

You are a tired software engineer trapped inside an abandoned source code archive known as the **Grave of Source**.

Deep below the repository lie forgotten projects, unstable packages, unresolved merge conflicts, and ancient bugs.

Your mission is simple:

- Collect enough Productivity Tokens
- Find the Exit Build
- Avoid being crushed by Dependencies
- Survive the ever-growing Technical Debt

Failure is not an option.

The deadline is tomorrow.

---

## Core Gameplay

Each level consists of a tile-based cave.

The player can move in four directions:

- Up
- Down
- Left
- Right

Digging through source code blocks opens new paths through the cave.

Certain objects are affected by gravity and may fall when their support is removed.

Players must carefully manipulate the environment to reach objectives while avoiding hazards.

---

## Game Objects

### Source Code

The basic terrain.

Can be dug through by the player.

Represents undocumented legacy systems.

---

### Productivity Tokens

The primary collectible.

Players must collect a required amount before the Exit Build becomes active.

Equivalent to classic gems or diamonds.

---

### Features

- Crush bugs with falling dependencies
- Collect productivity before the deadline
- Navigate ancient source repositories
- Trigger large dependency cascades
- Survive dangerous merge conflicts
- Discover hidden documentation
- Experience authentic software engineering pain
- AGA enhanced

---

### Dependencies

Heavy package crates that obey gravity.

They can:

- Fall vertically
- Roll off unstable edges
- Crush bugs
- Crush players

Improper dependency management can be fatal.

---

### Legacy Bugs

Hostile creatures roaming the repository.

Characteristics:

- Follow predictable movement patterns
- Become dangerous on contact
- Can be eliminated using falling dependencies

Destroyed bugs leave behind Productivity Tokens.

---

### Technical Debt

Special indestructible obstacles.

Can never be removed.

Players must work around them.

Just like in real life.

---

### Merge Conflicts

Animated barriers that periodically open and close.

Timing and observation are required to pass safely.

---

### Coffee

Temporary power-up.

Effects:

- Increased movement speed
- Short-term immunity against minor bugs

Duration is limited.

Following the effect, the player experiences a brief exhaustion period.

---

### Documentation

Rare collectibles.

Provide bonus points and level completion bonuses.

Many players will never discover all of them.

---

## Exit Build

The level exit.

Initially locked.

Activates once the required number of Productivity Tokens has been collected.

Entering the Exit Build completes the level.

---

## Advanced Mechanics

### Cascading Dependencies

Removing a single block may trigger large chain reactions.

Experienced players can use this to clear large portions of a level.

---

### Refactoring Zones

Special areas where dependencies become lighter and easier to manipulate.

Designed to create puzzle opportunities.

---

### Race Conditions

Invisible hazards appearing in later levels.

Their behavior changes between attempts.

Players must learn patterns through observation.

Even the developer may not fully understand them.

---

## Progression

The campaign is divided into themed chapters:

### Chapter 1: Hello World

Introduction to basic movement and gravity mechanics.

### Chapter 2: Legacy Systems

Introduction of Technical Debt and Legacy Bugs.

### Chapter 3: Dependency Hell

Large chain reactions and complex environmental puzzles.

### Chapter 4: Continuous Integration

Moving obstacles, timing puzzles, and Merge Conflicts.

### Chapter 5: Grave of Source

Advanced levels combining all gameplay systems.

### Final Chapter: Production Deployment

The most dangerous repository ever created.

Nothing has been tested.

---

## Scoring

Players earn points by:

- Collecting Productivity Tokens
- Defeating Bugs
- Finding Documentation
- Completing levels quickly
- Finishing without consuming Coffee

---

Reach the final deployment.

Push the successful build.

Save the repository.

Go home.
